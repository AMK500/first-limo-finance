# فرست ليموزين - تطبيق الآلة الحاسبة المالية (First Limo Finance)

تطبيق أندرويد مالي احترافي متكامل مصمم باللغة العربية مع دعم كامل للاتجاه من اليمين إلى اليسار (RTL)، مخصص لإدارة التدفقات المالية لسائقي ومندوبي "فرست ليموزين"، مع فصل تام ودقيق بين أموال الشركة والأموال الشخصية (النقدية)، وربط البيانات سحابيًا برقم الهاتف مع دعم العمل دون اتصال (Offline-First) ونظام التحديثات الذاتية المباشرة من داخل التطبيق عبر GitHub Releases.

---

## 🌟 الميزات الرئيسية

### 1. المنطق المالي الدقيق والمنفصل
- **تحصيل فرست ليموزين**: يضاف إلى إجمالي التحصيل وإلى حساب فرست ليموزين.
- **مصاريف فرست ليموزين**: تخصم من رصيد فرست ليموزين.
- **الكوميسيون (دخل شخصي للسائق)**:
  - يُخصم تلقائياً من رصيد فرست ليموزين.
  - يُضاف تلقائياً وفورياً إلى النقدية الشخصية.
- **النقدية (الأموال الشخصية)**: حساب منفصل تماماً، يشمل الكوميسيون + الإيداعات الشخصية − المصاريف الشخصية.
- **صافي حساب فرست ليموزين**:
  $$\text{رصيد فرست ليموزين} = \text{التحصيل} - \text{المصاريف} - \text{الكوميسيون}$$
- **إجمالي السيولة في الحسابين معاً**: يوضح إجمالي الأموال المتاحة فعلياً.

### 2. الحساب الشخصي والحفظ السحابي
- تسجيل الدخول برقم الهاتف ورمز التحقق (SMS OTP).
- حفظ واستعادة كافة البيانات تلقائياً عند تغيير الهاتف أو إعادة تثبيت التطبيق.
- المزامنة اللحظية بين عدة هواتف في نفس الوقت.
- العمل الكامل دون اتصال بالإنترنت (Offline-First) مع مزامنة تلقائية عند توفر الشبكة.

### 3. التحديثات الذاتية من داخل التطبيق (In-App OTA Updates)
- فحص تلقائي للإصدارات الجديدة عبر GitHub Releases API:
  `https://api.github.com/repos/AMK500/first-limo-finance/releases/latest`
- إشعار منبثق للمستخدم عند توفر تحديث جديد مع عرض ما تم تعديله (Changelog).
- تنزيل ملف الـ APK مباشرة داخل التطبيق مع شريط تقدم.
- تشغيل مثبت الحزم التلقائي لترقية التطبيق دون فقدان أي بيانات.

### 4. التصدير والتقارير
- تصدير سجل العمليات والملخص المالي إلى ملفات **Excel / CSV** مدعومة باللغة العربية (UTF-8 BOM).
- إمكانية مشاركة التقرير فورياً عبر واتساب أو البريد.

## 🚀 طريقة إصدار ونشر تحديث جديد عبر GitHub

كل ما عليك عند تجهيز أي تحديث جديد للتطبيق:
1. قم بزيادة رقم الإصدار في `app/build.gradle.kts` (مثلاً من `1.0.0` إلى `1.1.0`).
2. قم ببناء ملف الـ APK (من خلال `Build > Build Bundle(s) / APK(s) > Build APK(s)` في Android Studio).
3. توجه إلى مستودع GitHub الخاص بك:
   [AMK500/first-limo-finance/releases](https://github.com/AMK500/first-limo-finance/releases)
4. اضغط على **"Draft a new release"**.
5. اكتب اسم الـ Tag (مثال: `v1.1.0`).
6. اكتب عنوان الإصدار وملاحظات التحديث في خانة الوصف.
7. قم بسحب وإسقاط ملف الـ `app-release.apk` في قسم المرفقات (Attach binaries).
8. اضغط **"Publish release"**.
9. **النتيجة**: بمجرد فتح التطبيق لدى أي مستخدم، سيظهر له فوراً إشعار التحديث وزر التحميل والتثبيت المباشر!

## 🛠️ المكدس التقني (Tech Stack)

- **اللغة**: Kotlin
- **واجهة المستخدم**: Jetpack Compose + Material 3 (Arabic RTL native)
- **قاعدة البيانات المحلية**: Android Room Database (SQLite)
- **السحابة والمصادقة**: Firebase Authentication (Phone SMS) & Cloud Firestore
- **الشبكة والتحديثات**: OkHttp & Gson
- **التصدير**: FileProvider & CSV UTF-8 Engine
